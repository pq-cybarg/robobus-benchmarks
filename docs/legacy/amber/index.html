Move data between machines and robots

robobus is one shared-memory bus that every protocol plugs into, so a stream from one world reaches another without a bespoke gateway. Bridges you did not have to write link the fabric.

  • 108 protocol adapters: ROS 1 / ROS 2 / LSL, DDS, MQTT, Kafka, Zenoh, ZeroCM, serial, CAN, and more
  • Record and replay with no framework installed: rosbag2, ROS 1 bag, XDF, MCAP (Foxglove), EDF (BioSig)
  • Visualize live in the browser: typed ROS 2 messages stream into Foxglove or a built-in 3D viewer
  • Every recording is sealable at rest under the same post-quantum chain

Keep it secure or compliant

One post-quantum engine, four insertion points. Greenfield systems adopt the native sealed wire; deployed systems that cannot change get the same protection grafted in or simply inventoried.

  • CNSA 2.0 (ML-KEM-1024 + ML-DSA-87), FIPS 203 / 204 / 205, verified against liboqs and OpenSSL 3.6
  • Regimes: CNSA 2.0 / NSS, FIPS 140-3 boundary via the sidecar, CSfC two-layer, NIST levels 1 to 5
  • Modes: wrap (bump-in-the-wire), key-exchange graft, signature graft, observe (crypto inventory)
  • Retrofit path for legacy PLC, SCADA, avionics, space and financial rails
