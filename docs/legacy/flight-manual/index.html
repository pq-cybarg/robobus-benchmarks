What this page is

This is the operator manual for the entire robobus stack, served from operator/ on this machine only (127.0.0.1). The right-hand console runs allowlisted tasks - doctor, ship-set show, NASA/ICS/avionics/privacy fragment compile + isolation verify, checksums, portable zip, census. It is not a remote control plane and it will not execute a shell string.

Lab / hobbyist is the default clone: optional crypto, all adapters, laptop skips allowed. Production, CSfC, and NASA slices are opt-in subsets, not a replacement install. Cypherpunk / privacy stays a first-class profile.

Counts and library names on this page are filled from the live catalog (/api/catalog) and the live host probe (/api/host). Autodetect is the default; the target selector overrides it so you can read configs for other OS/ISA combinations, MCU boards, phones, PLCs, and WASM without leaving the page. Compile/doctor still execute on this machine. If a README and the catalog disagree, believe the catalog and python3 bench/robobus_census.py.

2 / safety

      
Local bind, allowlist, no arbitrary shell

    •

        Lab / csfc / crypto-toe have no codec fragment

10 / crypto

      
Suites, backends, what "required" means

      

        Default suite is hybrid3 (X25519+ML-KEM-768). CNSA 2.0 is
        cnsa20 (ML-KEM-1024 + ML-DSA-87 + AES-256-GCM + SHA-384) and is
        stricter than "any NIST PQC suite." Handshake (ML-KEM) is per session; AEAD is
        per message.
      

      

      

        
suitewhen

        
          
classicalinterop / constrained peer; not quantum-safe

          
nist1/3/5pure PQC by NIST category + SHA-3

          
hybrid3lab/hobbyist recommended default

          
hybrid5highest hybrid assurance

          
cnsa20NSS / production hash SHA-384 (SHA-2 per CNSA)

          
nist5-kmacKeccak-native KDF (KMAC256), no HMAC nesting

          
sphincs5 / falcon5alt signatures

          
csfctwo independent AEAD layers

        
      

      

        Python extras: crypto (pyca), pq (quantcrypt). Direct-EVP
        (ROBOBUS_PQ_BACKEND=openssl) needs OpenSSL 3.5+ with ML-KEM/ML-DSA.
        Compiled AEAD (ROBOBUS_AEAD=fast / make native-aead) is a
        third path; generated _aead_fast.c is gitignored. "openssl backend"
        is not a CMVP-validated module - robobus crypto compliance --standard cnsa20 --suite cnsa20
        is the honest check.
      

    


    

      
11 / hashing

      
CNSA 2.0 is SHA-384 / SHA-512, not SHA-256

      

        
policyfileswho

        
          
allSHA-384, SHA-512, SHA3-384, SHA3-512, SHA-256hobbyist / tag-release default

          
cnsa20SHA384SUMS + SHA512SUMS onlyproduction evidence pack; no SHA-256

          
fips202SHA3-384 + SHA3-512 onlyFIPS 202 extra

        
      

      

        Sigstore typically still hashes SHA-256 internally; that does not make SHA-256
        a CNSA 2.0 algorithm. Verify-all with --require-cnsa fail-closes if
        SHA384SUMS / SHA512SUMS are missing. SHA-256, if present, is verified last and
        labeled interop.
      

      
make checksums              # policy all
make checksums-cnsa         # policy cnsa20
make checksums-verify-all   # --require-cnsa

    


    

      
12 / doctor

      
What doctor actually checks

      

        Interpreter / conda prefix, whether rclpy / rospy /
        pylsl import in this env, liblsl, DDS RMW, shm ring round-trip.
        ROS 1, ROS 2, and LSL live in separate conda envs - a missing rclpy
        in the LSL env is expected.
      

      

        It does not (in lab) require OpenSSL, HAVE_EVP_PQC,
        librobobus, librbcodec, or transport extras. Fail-closed profiles
        (privacy/cypherpunk, csfc/cnsa, crypto-toe,
        ics, avionics, space/nasa) exit 1 when their
        crypto/backend bar is not met.

15 / personas

      
One slice each (combining rows is allowed; one install is not all of them)

      

        

          A. macOS roboticist
          
./bootstrap.sh
source env/activate-ros2.sh
robobus doctor
make e2e

          Isolated Miniforge, three Python 3.12 envs, shm bus. Not automatic: pip transport extras, librobobus, native AEAD, MCU ports.
        

        

          B. Python bus only
          
from robobus.bus import Publisher, Subscriber
pub = Publisher("telemetry")
sub = Subscriber("telemetry", start="new")
pub.put_raw(b"hello")

          No ROS. Encryption: pip install -e ".[crypto]".
        

        

          C. Existing broker
          
robobus mqtt|kafka|nats|... then -h for the extra. Seal that hop with --security.

        

        

          D. Field protocol
          
robobus adapters then robobus dnp3 -h. Use the adapter table on this page.

        

        

          E. C seal only
          
Build librobobus. Include robobus.h. Do not expect rb_modbus_*.

        

        

          F. 34-language codec FFI
          
Build librbcodec. Probes: bench/c_abi_probes.py. Compose with librobobus if you need RBX1.

        

        

          G. MCU / PLC
          
rb_config.h flags for your link line. PLC: native/plc61131/ Structured Text, separate from C ports.

        

        

          H. FIPS / CNSA evaluator
          
COMPLIANCE.md + robobus crypto compliance --standard cnsa20 --suite cnsa20. Ship-set csfc or crypto-toe.

        

        

          I. Mobile SS7 / 5G-SBI lab
          
robobus mobile routes, profile lab_open5gs. Not a public cellular stack.

        

        

          J. Phone / Termux / iOS
          
Bus + PQC in Python; reach a ROS graph over a transport. liblsl is the realistic native extra.

        

        

          K. NASA flight image
          
Profile space / nasa. Compile the 13-codec fragment from this page. Isolation verify before you ship the image.

        

        

          L. Cypherpunk
          
Profile privacy / cypherpunk. Tor/Sphinx/WG allowed; no vendor cloud; fail-closed if no local crypto. Bench shims out of SBOM.

        

        

          M. CCaaS / Liberty telephony
          
Profile telecom / ccaas / liberty. SIP and IETF SRTP are robobus sip / robobus srtp. GE Fanuc PLC is robobus ge_srtp. SS7/Diameter is robobus mobile on top.

17 / MCU

      
Embedded C ports vs host FFI

      

        native/embedded/rb_*.c plus rb_codec_abi.h. MCU builds
        honor RB_ADAPTER_* / RB_TRANSPORT_* in rb_config.h.
        Host lang-conformance ignores those flags and compiles every codec into one dylib.
        The fragment Compile button is the host analogue of an MCU slice: only those
        .c files reach cc.

3GPP / mil / intel lab routes

21 / gotchas

      
Intersections that bite

      
    
        
  • start="new" subscribers skip frames already in the ring. Lapping a 1024-slot ring under a flood is overwrite, not "recv_batch failed."
    • 
        
  • DDS robobus dds needs rclpy. Fast take-drain is the default; the executor path is slower and can drop.
    • 
        
  • PROTOCOL.md may still say Rust/JS bindings are "on the roadmap"; bindings/ and tests say they exist. Prefer the bindings tree.
    • 
        
  • A pytest skip is not a green pass of that slice.
    • 
        
  • SHA-256 in a SUMS file is interop, not CNSA 2.0.
    • 
        
  • Doctor lab must not be used as a production gate. Use --profile csfc or space.
    •
