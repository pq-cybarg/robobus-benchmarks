1. Scope

This specification describes the robobus middleware as implemented in this tree: shared-memory ring, codec and RBX1 frames, protocol adapters, transports, ship-sets, compile fragments, language bindings, and the local operator console. It does not specify a CMVP-validated module (see the FIPS sidecar document). If this page and a README disagree, believe the live census (python3 bench/robobus_census.py) and the named source of truth.

Layers are independent. Linking librobobus does not give Modbus. Linking librbcodec does not encrypt. librbxport and librbcrypto are bench-only and listed in production exclude_from_sbom.

3. Wire bytes (normative: PROTOCOL.md)

All integers little-endian. Codec serialises IEEE-754 doubles as LE on every host, including big-endian s390x.

3.1 Ring

One mmap file per channel: <dir>/<channel>.ring. Dir: /dev/shm/robobus (Linux), $TMPDIR/robobus (macOS), %TEMP%\robobus (Windows), $PREFIX/tmp (Termux), or $ROBOBUS_DIR. Header 64 bytes, magic ROBOBUS\x01. Slot: u64 seq, u32 length, payload. Single producer; any number of subscribers. start="new" skips frames already in the ring. Lapping a ring is overwrite, not a recv bug.

3.2 Codec frame

u8 type (1 float64[], 2 int32[], 3 utf8, 4 JSON, 5 bytes, 6 schema) + u64 stamp_ns + body. Type 6: schema_id u32 + packed struct.

3.3 RBX1 crypto frame

off 0  4s  "RBX1"
off 4  u8  alg     1=AES-256-GCM  2=ChaCha20-Poly1305 (not FIPS)
off 5  u8  flags
off 6  12  nonce
off 18 ..  ciphertext || 16-byte tag

18-byte header is AEAD associated data. CSfC suite seals twice under two HKDF keys.

3.4 Handshake

Out of band: responder publishes suite, KEM pub, token = Sign(kem_pub), identity pub. Session key = HKDF(ss, salt=H(kem_pub||ct), info="robobus-session"). Transport-agnostic.

5. Languages (three different claims)

  1. 34 LANGS - C-ABI codec identity against librbcodec. Laptop skip if toolchain missing; Docker image does not skip.
  2. 14 Schema.render - C, C++, Rust, Go, Java, C#, TypeScript, Python, Julia, MATLAB/Octave, Swift, Kotlin, Ruby, Lua.
  3. 3 packaged - crates.io / npm / Maven (seal+codec, not 108 adapters).
