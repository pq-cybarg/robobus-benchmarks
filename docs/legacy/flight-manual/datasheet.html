What it is

A host-local shared-memory bus that links ROS 1, ROS 2, LabStreamingLayer, 16 wire transports, and 108 protocol codecs. Optional post-quantum seal (ML-KEM / ML-DSA / AES-256-GCM). The public clone is the lab / hobbyist ship-set: optional crypto, laptop skips allowed. Production, CSfC, NASA/space, ICS, and avionics slices are opt-in subsets.

Not a CMVP-validated cryptographic module. Approved algorithms plus a FIPS sidecar architecture; a CST lab issues certificates. See FIPS sidecar.

Crypto (honest)

  • Per-message AEAD: AES-256-GCM (RBX1). Handshake: ML-KEM + ML-DSA (suite-selected).
  • CNSA 2.0 suite cnsa20: ML-KEM-1024 + ML-DSA-87 + AES-256 + SHA-384. SHA-256 is interop, not CNSA 2.0.
  • Release hashes: policy cnsa20 writes SHA384SUMS + SHA512SUMS only. Policy all also emits SHA-3 and SHA-256.
  • FIPS sidecar isolates AEAD keys in a separate process. That is the module boundary sketch, not a certificate.

Platforms

Bus + PQC: macOS arm64/x64, Linux x86_64/aarch64/armv7, Windows x64, Raspberry Pi, Termux/Android, iOS a-Shell/embed, Alpine musl, QEMU ppc64le/riscv64/s390x (LE wire even on BE CPU). ROS 1/2 + LSL: desktop + Pi via conda/RoboStack. MCU: ESP32, STM32, nRF52, RP2040, Cortex-M, RISC-V (static codecs). PLC: IEC-61131 ST under native/plc61131/. Override the flight-manual target selector to read each ABI without leaving this site.
